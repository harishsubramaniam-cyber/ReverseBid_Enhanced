Running ReverseBid on Windows

Written for someone who has never run a program out of a folder before. Everything happens on your own PC — no website, no account, nothing to buy. Steps 1 to 3 you do once; after that, starting it is a double-click.

  • Windows 10 / 11
  • ~10 minutes
  • Nothing to buy

Setting it up

Do this once
1

Install Python

Python is the language the app is written in. Your PC almost certainly does not have it.

  1. Go to python.org/downloads/windows.
  2. Click the big yellow Download Python 3.x button, then open the file that downloads.
  3. On the very first screen, tick “Add python.exe to PATH” at the bottom.
  4. Click Install Now, then Close.
This is the step people get wrong

That PATH tick box is easy to miss and everything else depends on it. If you have already installed Python without it, run the installer again and choose Modify.

Check it worked. Press the Windows key, type cmd, press Enter. A black window opens. Type this and press Enter:

Command Prompt
python --version

You should see something like Python 3.12.4. If you see “not recognized”, or the Microsoft Store opens instead, jump to If something goes wrong.

2

Unzip the app

  1. Find reversebid.zip — probably in your Downloads folder.
  2. Right-click it → Extract All…
  3. A box asks where to put it. Delete what is in it, type exactly C:\ — just those three characters — and click Extract.
  4. Open This PC → Local Disk (C:) → ReverseBid. That folder is the app.

Directly inside it you should see:

C:\ReverseBid\  →  START HERE.txt · windows-setup.bat · windows-start.bat · README.md · app\ · docs\ · tests\
Cannot see those files?

You are looking at the wrong folder. The right one has README.md sitting directly inside it. If you see a single folder and nothing else, open that folder.

3

Run the setup

Double-click windows-setup.bat.

A black window opens and text scrolls past for a minute or two — it is downloading the pieces the app needs and building some demo data to play with. When it is done it says “Setup finished.” Press any key to close it.

A blue box may appear

“Windows protected your PC” shows up because the file arrived from the internet. Click More info → Run anyway. To stop it asking: right-click the file → Properties → tick Unblock → OK.

Using it

Every time
4

Start the app

Double-click windows-start.bat. Two things happen:

  • A black window opens and stays open. Leave it alone — that window is the app running. Closing it stops the app.
  • Your browser opens at localhost:8000. If it does not, type that into the address bar yourself.
If Windows asks about the firewall

You can safely click Cancel. The app only needs to talk to your own browser, not to the network.

5

Sign in and look around

The setup built a small demo company with real-looking auctions. Sign in as any of these — the password is demo1234 for all of them.

Who you areEmailWhat you see

A five-minute tour, signed in as the buyer

Now try it from the other side

Open a second browser window in private mode (Ctrl+Shift+N in Chrome or Edge), go to localhost:8000, and sign in as supplier1@example.com. Place a bid there and watch it appear in the buyer's window a few seconds later.

Stopping, and starting again tomorrow

  • To stop: click the black window and press Ctrl+C, or just close it.
  • To start again: double-click windows-start.bat. That is all — the setup never needs running again.

Everything you do is saved inside C:\ReverseBid\data\ and will still be there next time.

Turning on real emails

Out of the box the app sends nothing. Every message goes to the Outbox page instead, so you can see exactly what suppliers would receive without a real email escaping. That is deliberate — leave it that way while you are experimenting.

1. Get an app password from Gmail

Your ordinary Gmail password will not work for this.

  1. Go to myaccount.google.com/apppasswords. You need 2-Step Verification on first; Google will walk you through it if not.
  2. Name it ReverseBid and click Create.
  3. Google shows a 16-character password. Copy it now — you cannot see it again.

2. Tell the app about it

  1. In C:\ReverseBid, find .env.example.
  2. Copy and paste it (Ctrl+C, Ctrl+V), then rename the copy to exactly .env — nothing before the dot.
  3. Right-click .env → Open with → Notepad, fill in these lines, and save:
.env — in Notepad
RA_SMTP_HOST=smtp.gmail.com
RA_SMTP_PORT=587
RA_SMTP_USER=your.name@gmail.com
RA_SMTP_PASSWORD=the16characterpassword
RA_MAIL_FROM=your.name@gmail.com
RA_SECRET_KEY=any-long-random-line-of-text-only-you-know
If Windows hides file extensions

Your copy may really be called .env.txt, which will not work. In File Explorer: View → tick File name extensions, then rename it properly.

3. Restart and check

Close the black window, double-click windows-start.bat again. The blue “emails are in preview mode” banner on the dashboard disappears, and localhost:8000/healthz now says "email_mode":"smtp".

Clear the demo data first

The demo suppliers have invented addresses. Before you publish anything for real with email switched on, wipe them — see the next section.

Starting fresh with your own suppliers

Stop the app, then press the Windows key, type cmd, press Enter, and run:

Command Prompt
cd /d C:\ReverseBid
python seed.py --reset

That wipes everything and rebuilds the demo from scratch. To have nothing at all instead: delete the data folder inside C:\ReverseBid, start the app, and click Create an account on the sign-in page to make your own buyer login.

If something goes wrong

What you seeWhat to do
'python' is not recognized Python went in without the PATH box ticked. Reinstall from python.org with it ticked — or try typing py everywhere you would type python.
Typing python opens the Microsoft Store Windows key → search “app execution aliases” → open it → switch off the two entries named python.exe and python3.exe. Then install from python.org.
Address already in use, or the page will not load Something else is on port 8000. In Command Prompt: cd /d C:\ReverseBid then python -m uvicorn app.main:app --port 8001, and use localhost:8001.
The black window flashes and vanishes Open Command Prompt, cd /d C:\ReverseBid, then type windows-start.bat and press Enter. The error stays on screen so you can read it.
“Windows protected your PC” More info → Run anyway. It is only because the file was downloaded.
The browser page will not load at all Check the black window is still open. If it closed, start it again.
Emails are not arriving Open the Outbox page. Messages marked outbox mean no mail server is configured yet. Marked failed, the reason sits beside them — nearly always a mistyped app password.
Everything looks broken after a change Stop the app, run windows-setup.bat again, then start it.

Doing it by hand instead

The two .bat files only save you typing. The same thing in Command Prompt:

Command Prompt
cd /d C:\ReverseBid
python -m pip install -r requirements.txt
python seed.py
python -m uvicorn app.main:app --port 8000

Then open localhost:8000, and press Ctrl+C in that window to stop.

There is also a built-in test that walks a complete auction — bidding rules, emails, awards, reports — and prints a tick beside each of about seventy checks. It uses a temporary database, so it never touches your real data:

Command Prompt
python tests\test_end_to_end.py
